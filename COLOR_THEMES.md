# ServiceTones Color Themes Library

## Theme 1: Navy + Gold + Cream (ORIGINAL - SAVED FOR FUTURE USE)

### Primary Colors
- **Navy/Slate-900**: #1a365d - Main buttons, headings, avatars
- **Gold/Amber-400**: #FFB81C - Trust badges, accents
- **Cream/Beige**: #F5F1E8, #FFF8F0 - Backgrounds

### Color Mapping
- Primary buttons: `from-slate-900 to-slate-800`
- Secondary buttons: Slate border with slate-900 text
- Headings: Slate-900
- Body text: Slate-600
- Borders: Slate-200, slate-300
- Backgrounds: Cream gradient `from-amber-50 via-white to-slate-50`
- Hover backgrounds: Slate-100
- Badge accents: Amber-400, emerald-400, blue-400

### Usage
Used from project inception through all pages: Landing, Services, Pricing, Help Center, Auth, Browse Projects, Browse Providers, and all components.

## Theme 2: Deep Teal + Cream + Copper (CURRENT - ACTIVE)

### Primary Colors
- **Deep Teal**: #0D5C63 - Main buttons, headings, primary elements
- **Copper/Rose Gold**: #D4A574 - Trust badges, accents, highlights
- **Cream/Beige**: #F5F1E8, #FFF8F0 - Backgrounds
- **Teal Grays**: Teal-600, teal-700, teal-800 - Secondary text, borders

### Color Mapping
- Primary buttons: `from-teal-900 to-teal-800`
- Secondary buttons: Teal border with teal-900 text
- Headings: Teal-900
- Body text: Teal-700
- Borders: Teal-200, teal-300
- Backgrounds: Cream gradient with teal undertones
- Hover backgrounds: Teal-100
- Badge accents: Copper-500, emerald-600, blue-600

### Applied To
All pages: Landing, Services, Pricing, Help Center, Auth, Browse Projects, Browse Providers, Navbar, Cards, Buttons, Forms, Links

---

## How to Switch Themes
1. Find all color references in the codebase
2. Replace slate colors with teal colors
3. Replace amber accent with copper
4. Update gradient colors and shadow tints
5. Rebuild and test all pages
